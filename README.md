## 🌟 Overview

**AD Craft** is a modern B2B PropTech SaaS platform that helps real-estate brokers, builders, developers, and agencies automatically respond to leads generated from Meta, Instagram, Google Ads, websites, and property portals.

The platform uses conversational AI to:
- **Respond to new leads instantly, 24/7** (under 5 seconds response time)
- **Answer property questions** using uploaded brochures, floor plans, and pricing sheets
- **Qualify buyers automatically** (budget ceiling, preferred unit size, timeline, end-user vs investor)
- **Capture buyer requirements** with zero manual telecalling overhead
- **Recommend suitable properties** and available inventory
- **Follow up systematically** across 3, 7, and 14-day cadences
- **Book site visits** directly through Google Calendar / Calendly
- **Notify sales teams** on WhatsApp when high-intent buyers request physical showroom tours
- **Reduce lead leakage** caused by slow response times
